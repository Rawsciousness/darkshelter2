# DARKSHELTER 2

Live: https://adamidisch.github.io/darkshelter2/

The original studio website is preserved. An optional entrance banner adds Greek/English selection. Close with X or Escape, or enter by clicking the logo. Dismissal lasts for the current browser tab. Direct article links skip the banner.

Independent of the Claude studio repository. GitHub Pages: main at root. No build. Bookings remain local demonstrations.

After edits update version.json content hashes and the fallback in index.html, then run `node tools/generate-journal.mjs` and `node tools/generate-journal.mjs --check`.
